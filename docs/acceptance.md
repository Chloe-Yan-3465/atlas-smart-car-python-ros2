# 分级验收清单

## 普通电脑

- 安装 `.[cpu,dev]`，单元测试全通过。
- `tools/check_project.py` 的源码、ROS 清单、YAML 和六个模型校验全部通过。
- `tools/model_smoke.py` 能加载两份真实 ONNX 并完成推理。
- 图片目录回放时，丢线、人员/障碍、地标冷却和 crosswalk 爬行符合规则。
- 伪串口覆盖数据包、ACK、重连和退出停车。

## Atlas 台架

- 校验模型 SHA256，分别完成两份 OM 推理。
- `colcon build/test` 通过；五节点及固定话题图可观察。
- `dry_run:=true` 下验证感知超时和动作输出，不打开串口。

## ESP32 与实车

- 架空逐轮完成编码器方向、每圈计数、PID 与两秒失联停车。
- 验证停车包、错误包、方向故障和串口断开保护。
- 低速测试巡线，再分别测试七类检测语义；person/obstacle 必须最高优先级。
- 固化最终相机、模型阈值、动作时长、轮方向与 PID 参数并记录测试日期。

## 独立复现与交接记录

未参与主要开发的成员应在干净环境中按 [根 README](../README.md)完成克隆、Git LFS 获取、依赖安装、配置、启动和最小验证。记录测试日期、设备编号、稳定分支、完整 Commit ID、各命令退出码及故障。未在 Atlas/ESP32 上执行的条目一律标记“待验证”，不能根据普通电脑测试判定通过。

梦工厂规范还要求确认内部 GitLab 项目路径、个人账号与真实 Author、维护人和交接日期；如存在大模型，还需验证 NAS 稳定链接。当前待补项与表格入口见 [交接记录](handover.md)。正式验收前由项目组长核对，勿填写未经确认的结果。
