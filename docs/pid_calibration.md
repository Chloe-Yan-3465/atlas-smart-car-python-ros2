# 编码器与 PID 标定

1. 架空车辆，断开舵机及非必要负载。
2. 在 `config.h` 开启单轮自检，从 M1 到 M4 逐轮测试正负目标。
3. 正目标必须得到正测量 RPM；否则调整该轮 `ENCODER_SIGN` 或交换 A/B。
4. 实测输出轴一圈脉冲数，分别填写 `COUNTS_PER_WHEEL_REV`。
5. 先设 `KI=KD=0` 调 Kp，再增加 Ki 消除静差，最后少量 Kd 抑制快速变化。
6. 标定前馈和启动 PWM，保证低速能启动且不突跳；检查积分限幅与最大 PWM。
7. 比较不同电池电压下相同目标 RPM，确认闭环误差满足要求。
8. 恢复 `PID_SELF_TEST_MODE=false`，验证零速、换向、方向故障和两秒失联停车。

参数只可通过实车记录确定；仓库默认值来自第 19 组参考，不代表当前车辆已标定。
